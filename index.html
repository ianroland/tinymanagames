How we build

Small studio, three rules

Agentic builds

AI agents do the building: code, systems, iteration. A human sets the direction, plays every version and decides what ships.

Web stack first

Mainly HTML, CSS and JavaScript. No install and no launcher. Open the link and play with keyboard, controller or touch.

Retro on purpose

Chunky pixels, bright palettes and arcade feel from the 32-bit era, with the depth of a modern career game underneath.
